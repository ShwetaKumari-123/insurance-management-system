# Insurance Management System

## Introduction

The Insurance Management System is a Python-based project designed to manage basic insurance operations such as customer registration, policy creation, premium payments, and claim management.

In many small insurance agencies, these tasks are handled manually using paper records or spreadsheets, which can lead to errors, delays, and difficulty in tracking information.

This system provides a simple digital solution that stores data in structured text files and allows administrators and customers to manage insurance processes efficiently.

The project demonstrates the use of Python programming concepts such as functions, file handling, conditional statements, and menu-driven systems to automate real-world insurance workflows.

## Features

- Add customer records
- Create insurance policies
- Record premium payments
- Raise insurance claims
- View stored data

## Technologies Used

- Python
- File Handling (.txt files)
